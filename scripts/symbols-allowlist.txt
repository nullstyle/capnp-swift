# Undefined symbols the Zig core (CapnpCore.xcframework) may import from
# libSystem. scripts/check-symbols.sh requires this list to be EXACT: every
# symbol any slice imports is listed here, and every entry is imported by at
# least one slice. One symbol per line, Mach-O spelling (leading underscore).
#
# Adding an entry is a review decision: say in the commit which core code
# needs it. Never add ___ulock_*, ___getdirentries64, _posix_spawn* or
# _pthread_create here; the script fails on them regardless (a KNOWN SPI
# section between "# BEGIN KNOWN SPI" / "# END KNOWN SPI" markers would let
# the default run pass them with a banner, but `--strict` never does; none is
# needed any more).
#
# Origins were traced from relocations in the arm64 slice (M0, capnp-zig
# v0.20.0: abi.zig + selftest.zig -> conn.zig -> rpc.peer.Peer). Since the
# v0.21.0 pin the slices are built with `-Dfd-passing=false` (handoff H1), so
# capnp-zig's fd closer, fd budget and AF_UNIX transport are compiled out:
# the core imports exactly these 13 symbols and nothing else, and the former
# KNOWN SPI section (___ulock_wait2, ___ulock_wake, _pthread_create) is gone.
# `scripts/check-symbols.sh --strict` passes (plan D7 closed).
